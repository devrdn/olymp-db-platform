## `npm run typecheck` generates before it checks

`PageProps` and the other route types are generated by Next, into `.next/types`,
and nothing else writes them. A bare `tsc --noEmit` therefore passes on a
working tree that has been built and fails on a fresh checkout — which is
exactly the difference between a developer's machine and CI, where typecheck
runs before build. `next typegen` produces them without a full build, so the
script runs it first.
