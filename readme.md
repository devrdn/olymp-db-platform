# DB Contest

Платформа для проведения университетских SQL-олимпиад формата «Детектив». Студенты получают историю преступления и доступ к игровой базе данных, пишут SQL-запросы через веб-интерфейс, отвечают на вопросы и в итоге находят преступника.

## Возможности

- **Для студентов** — личный профиль с прогрессом, страница олимпиады с историей преступления и таймером, SQL-консоль с подсветкой синтаксиса и историей запросов, отправка ответов на вопросы с автоматической проверкой.
- **Для администраторов и менеджеров олимпиад** — конструктор олимпиад (история, вопросы, эталонные ответы, игровая схема), управление пользователями и ролями, настройка уровня SQL-доступа для каждой олимпиады, тип записи (открытая или по приглашению) и ограничение доступа по IP-диапазонам, live-мониторинг хода соревнования, панель журнала запросов с фильтрами и экспортом, отчёты и лидерборды.
- **Безопасность и изоляция** — каждый участник работает со своей копией игровой базы данных и не может повлиять на других; все запросы проходят валидацию и выполняются с жёсткими лимитами.
