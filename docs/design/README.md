## Как посмотреть макет

```bash
open docs/design/preview.html
```

Страница следует теме операционной системы: переключите светлую и тёмную —
пересоберётся всё, кроме блоков сравнения, зафиксированных намеренно.

## Принятое направление

«Чистовик» — выбран из трёх проработанных вариантов. Палитра взята из варианта
«Картотека», метод компоновки и типографики снят с документации Tailwind CSS
чтением вычисленных стилей живой страницы, а не по памяти.

Три находки, которые определили результат и которых не видно на скриншоте:
заголовок набран **весом 400**, а не 700; трекинг −0,05em при интерлиньяже 0,98;
прозрачность линеек между темами **удваивается, а не зеркалится** — 5 % чёрного
на белом против 10 % белого на чёрном.

## Что проверяется автоматически

Контраст ≥ 4,5:1 для текста и ≥ 3:1 для границ интерактивных контролов в обеих
темах. Скрипт переносится в CI на шаге 2 раздела 15 спецификации. На черновых
значениях он поймал три провала, невидимых визуально.
